# 五行穿衣 · 个人定制版 V2.1.6

一个基于 React、TypeScript 和 `lunar-javascript` 的纯前端五行穿衣应用。系统以个人四柱为长期基础，叠加流年、流月、流日与使用场景，输出主色、辅助色、点缀色、中性色和慎用色。

> 本项目属于传统文化参考工具，不构成科学、医疗、财务或其他决策建议。

## 本版已实现

### 1. 排盘与出生地设置

- 中国出生地支持省—市—区县三级联动，覆盖县、区、县级市、旗等县级单位
- 选择区县后自动回填经度、纬度和行政区划代码
- 中国地区时区默认东八区，可按实际出生地选择其他常用时区
- 海外出生地支持常用城市快捷选择和完全手动设置
- 根据出生日期和所选时区识别当时是否实行夏令时
- 真太阳时默认关闭，手动开启
- 经度修正与均时差计算
- 当地标准时间、世界协调时间、真太阳时和人工校正时间对照
- 专家校正时间最高优先级
- 子初换日、午夜换日、晚子时不换日三种配置
- 立春换年、节气换月
- 节气两小时、十二小时、二十四小时临界提示
- 真太阳时跨日期、跨时辰提示

### 2. 五层命理分析

1. **基础排盘层**：四柱、藏干、十神、纳音、地势、阴阳、五行数量。
2. **月令与旺衰层**：透干、藏干、月令、宫位、旺相休囚死、通根、生扶与耗泄克。
3. **格局与特殊结构层**：普通格局候选、从强/从弱候选、天干五合、六合、三合、三会、半合、冲刑害破。
4. **喜用判断层**：扶抑60%、调候20%、通关15%、格局与病药候选5%。
5. **专家校正层**：旺衰、格局、特殊结构、合化、扶抑、调候、通关、病药、喜用层级和人工分值覆盖。

复杂从格、专旺、化气格和合化先作为结构参考。只有专业人士确认“合化成立”后，相关组合才重新计算五行力量。

### 3. 动态推荐引擎

默认权重：

```text
个人命局 55%
流月     15%
流日     20%
流年      5%
场景      5%
```

最终分：

```text
最终分 =
个人命局分 × 55%
+ 流月分 × 15%
+ 流日分 × 20%
+ 流年分 × 5%
+ 场景分 × 5%
+ 通关修正
- 过量修正
+ 专业校正
```

包含：

- 喜用五行并非固定加分
- 当前环境已经过旺时触发过量扣分
- 慎用五行过旺时追加扣分
- 金木、水火、木土、土水、火金冲突的通关候选
- 主辅色相克时自动插入通关色或中性色
- 五行最终分限制在0—100

### 4. 场景模式

- 日常通勤
- 商务会议
- 社交约会
- 重要决策

场景只占5%，用于调整明度、饱和度、材质与面积比例，不覆盖个人命局喜忌。

### 5. 三种使用模式

- **大众模式**：配色、比例、穿搭示例和简短原因。
- **进阶模式**：四柱、旺衰、喜用、动态环境和评分依据。
- **专家模式**：开放完整时间口径、格局、合化、喜用、权重和人工分值配置。

### 6. 档案与隐私

- 出生信息首次录入只保存在页面内存
- 只有主动点击“保存到本机”才写入当前浏览器的本地存储
- 支持多个人档案
- 支持档案文件导入导出
- 支持专业配置单独导入导出
- 支持删除当前档案与清除全部本地数据
- 区县选择、经纬度回填、核心排盘和推荐均可离线运行


## V2.1.6 专业模式入口优化

- 首页默认保持“通用参考”，不展示与通用计算无关的专业选项。
- 切换到“个人定制”后，在日期和场景旁直接显示“简洁 / 详细 / 专业”三种查看方式。
- 未录入出生资料、未设置专业配置或配置未启用时，进入专业模式会给出对应提示。
- 仅查看专业模式不会让未启用的专业配置参与推荐计算。

## V2.1.5 界面与专业模式优化

- 页面可见文案统一使用中文，不直接展示内部状态代码
- 将“自动分析、系统判断、候选”等机械化表述改为更自然的说明
- 合冲刑害改为语义清晰的三列表格，状态居中、说明左对齐
- 五行评分表统一列宽、行高、数字对齐和移动端横向浏览
- 置信度由生硬百分比改为“依据较足、可作参考、仍需复核”
- 普通模式减少技术提示，专业信息集中在详细和专业模式

## 中国县级出生地数据

- 县级行政区划记录：2,849 条
- 经纬度采用通用地理坐标
- 绝大多数记录采用区县中心坐标；少数新设或调整区划会回退到地级市或省级近似中心，并在页面标注
- 数据已打包到前端资源中，不依赖第三方地图、定位或地理编码接口
- 详细来源与许可见 [`DATA_SOURCES.md`](./DATA_SOURCES.md)
